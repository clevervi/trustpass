# Additional paths that must never be delegated to a third-party model.
#
# This file ADDS to the rules. It cannot remove one.
#
# The never-transmit list -- .env, private keys, certificates, cloud and SSH
# material -- is hardcoded in scripts/tp-router.mjs and is not read from here,
# deliberately. A denylist that lives in the repository is one pull request away
# from being a shorter denylist, and TP-161 already made the argument: a guard
# the attacker can switch off is not a guard.
#
# One substring per line, matched case-insensitively against the repository
# path with forward slashes. Not a regular expression -- a config file that can
# define a pattern can define one that never finishes, and this project has
# already lost 500 seconds to catastrophic backtracking.
#
# If this file is missing, unreadable or malformed, every eligible file is
# treated as S1 and nothing is delegated. Claude carries on reading directly.

docs/legal/
