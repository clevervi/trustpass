# v0.1.0 — Foundation

**Released:** 2026-09-17
**Tag:** [`1f4bb5f`](https://github.com/clevervi/trustpass/commit/1f4bb5f)

The platform runs locally end to end. Product identity, passports, warranty and
lifecycle events are not implemented yet — this release establishes the
engineering foundation they will be built on.

This page describes only what the `v0.1.0` tag contains. Work merged to
`develop` afterwards, including the TrustPass ID and the issuer model, ships in
the next release; see [`CHANGELOG.md`](../../CHANGELOG.md) under Unreleased.

## What's new

### Infrastructure

- **Monorepo** — pnpm workspace with `apps/api`, `apps/web`, `packages/db`
- **Database** — Drizzle ORM over Postgres 18 with a health probe and a
  migration pipeline
- **API** — Hono HTTP service with `/health`, `/version` and a generated
  OpenAPI 3.1 document, where request validation and the published contract come
  from the same Zod schemas
- **Web** — Next.js 16 App Router frontend reporting live API and database
  status. A red indicator means the stack is genuinely broken, not that the page
  is a mock.

### CI

- Lint, typecheck and build on every push and pull request
- Tests against a real Postgres service, so integration tests that skip locally
  always execute somewhere
- Secret scan over the full history

### Documentation

- README, contributing guide and roadmap

## Verified before tagging

`GET /health` returned 200 with `database: up`, backed by a live Postgres
instance.

The tag was cut once before this, found broken on first execution, deleted and
re-cut. Building is not running, and a tag is a claim that a version works.

## Known limitations

- No product registration. A TrustPass ID cannot yet be issued.
- No public passport page.
- No warranty, lifecycle or ownership records.
- Not deployed. Local only.
